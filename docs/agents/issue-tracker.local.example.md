# Issue tracker local override (example)

Copy to `issue-tracker.local.md` (gitignored) and fill in:

```markdown
# Issue tracker local

- site: <your-site>.atlassian.net
- project_key: <KEY>
- board_url: https://<your-site>.atlassian.net/jira/software/c/projects/<KEY>/boards/<id>
- default_epic_name: Security Incident Response
```
